# California SEO Gold Standard

California is the reference model for future state expansion.

## Required page foundation

Every benchmark page should:
- Be indexable with a self-canonical URL.
- Use a unique, location-specific title, meta description and H1.
- Explain free-pickup qualification truthfully instead of promising every appliance is accepted.
- Include meaningful local route/access context rather than copied city-name substitution.
- Include a competitor-informed local-depth section marked `local-ranking-depth-20260918`.
- Link upward to the correct regional/state hub and sideways/downward to useful city and appliance-type pages.
- Include Service/WebPage/Breadcrumb structured data and FAQ content where useful.
- Include a same-page Formspree request form and customer-routing script.
- Include useful official disposal/bulky-item alternatives when a reliable government source materially helps the customer.
- Keep small communities consolidated into useful regional hubs when a standalone page would be substantially similar.

## Authentic image ranking standard

Every priority page should:
- Use an authentic, sharp, full-resolution appliance photo as the visible hero; do not use the logo as the page hero.
- Keep the hero `src`, `og:image`, Twitter image and `primaryImageOfPage` aligned to the same preferred real photo.
- Use a standard HTML `img` element with a crawlable `src`; never rely only on a CSS background image.
- Use concise descriptive alt text that identifies what is visible and the page context without stuffing search phrases.
- Place the preferred photo close to relevant appliance-pickup text and include a useful caption where the page already supports one.
- Give the image stable dimensions or responsive sizing so the page remains fast and avoids layout shift.
- Include every preferred image in `sitemap-images.xml`.
- Preserve original full-resolution user photos. Do not replace them with tiny compressed hero files.
- Reuse the same image URL consistently when the same photo appears more than once; do not create unnecessary duplicate URLs.
- Avoid generic stock photography, text-heavy graphics and logo-only previews on priority landing pages.

## Regional authority model

Every state rollout should follow a real hierarchy:
1. State hub.
2. Major metro or county hub.
3. Priority city pages with materially local content.
4. Appliance-type guides.
5. Direct contextual links between neighboring cities and the correct regional hub.

For Southern California, the benchmark cluster is Los Angeles, Los Angeles County, Orange County, San Gabriel Valley, Inland Empire, San Bernardino County and Riverside County. The priority east-west corridor connects La Crescenta and La Cañada Flintridge through Pasadena, West Covina, Covina, La Verne, San Dimas, Pomona, Claremont, Montclair, Chino, Ontario, Rancho Cucamonga, Fontana and San Bernardino.

## What cannot be manufactured on-page

Number-one rankings are not guaranteed by page edits. Continue building legitimate external authority through:
- Genuine customer reviews tied to completed service.
- A truthful service-area Google Business Profile.
- Consistent business name, phone and website citations.
- Local organizations, suppliers, property managers and community sites that voluntarily link to a useful resource.
- Search Console monitoring of clicks, impressions, CTR, average position and image-search performance.

The goal is not maximum page count or keyword repetition. The goal is the strongest helpful page for each real search market, supported by authentic proof, clear regional architecture and legitimate external reputation. Reuse this architecture in Oregon, Washington, Colorado and later states.
