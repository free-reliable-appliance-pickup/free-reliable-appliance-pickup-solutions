# California SEO Gold Standard

California is the reference model for future state expansion.

Every benchmark page should:
- Be indexable with a self-canonical URL.
- Use a unique, location-specific title, meta description and H1.
- Explain free-pickup qualification truthfully instead of promising every appliance is accepted.
- Include meaningful local route/access context rather than copied city-name substitution.
- Include a competitor-informed local-depth section marked `local-ranking-depth-20260918`.
- Link upward to the correct regional/state hub and sideways/downward to useful city and appliance-type pages.
- Include at least one authentic appliance image from the site's real inventory/work.
- Include Service/WebPage/Breadcrumb structured data and FAQ content where useful.
- Include a same-page Formspree request form and customer-routing script.
- Include useful official disposal/bulky-item alternatives when a reliable government source materially helps the customer.
- Keep small communities consolidated into useful regional hubs when a standalone page would be substantially similar.

The goal is not maximum page count. The goal is the strongest helpful page for each real search market, then reuse this architecture in Oregon, Washington, Colorado and later states.
