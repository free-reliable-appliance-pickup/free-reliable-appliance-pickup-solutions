Pickup Requests for Rental Properties

Landlords, property managers and rental-property owners can submit appliance pickup requests when washers, dryers, refrigerators, freezers, stoves, ranges or ovens need to be removed. Requests can involve a single qualifying appliance or several appliances from one or more units, but free pickup is always reviewed based on condition, local demand, access and available coverage.

For faster review: list every appliance separately, describe whether each one works, identify the property city or ZIP code, and explain where the appliances are located on the property.

Tenant Turnover and Unit Cleanouts

Appliances often need to be evaluated between tenants, after a remodel or when a property owner replaces older equipment. If an appliance still works, say what functions you have verified rather than assuming it is broken because it is being replaced. Reusable working appliances receive priority.

For vacant units, confirm whether the building is unlocked or whether someone must meet the pickup crew. For occupied properties, make sure access has been coordinated before a pickup time is confirmed.

How to Report Multiple Appliances

For each appliance, include the type, brand when known, approximate age if known, working condition and any visible damage. For example, a request might include one working refrigerator, one working dryer and one washer that does not spin. This is more useful than saying “three old appliances.”

Mixed loads may qualify when approximately 80% of the major appliances are working. A single nonworking appliance does not automatically qualify for free pickup.

Special rules: microwaves are accepted only with another qualifying major appliance. Dishwashers are considered only when included with two or more major working appliances.

Apartment and Multi-Unit Access

Access can determine whether a pickup can be scheduled. Include the floor level, stairs, elevator availability, narrow hallways, security gates, loading zones, parking restrictions and any tight doorway or turn. If an appliance is in a garage, storage room, basement or outside area, explain the route from the appliance to the pickup vehicle.

If building management requires a specific service entrance or pickup window, include that in the request before scheduling.

Photos and Condition Documentation

Clear photos help when several appliances are being reviewed. A full front photo of each appliance is the minimum useful starting point. Add model-label photos when practical and show obvious damage. For refrigerators and freezers, include an interior photo and say whether the unit is currently cooling or freezing. For laundry equipment, describe whether the washer fills, drains and spins and whether the dryer tumbles and heats.

Preparing Appliances for Removal

Remove tenant belongings, food and personal items and clear the path to the exit. Do not disconnect gas appliances unless the work is handled safely by someone qualified. Tell us whether appliances are already disconnected, but do not create unsafe conditions just to prepare for a request.

For working refrigerators and freezers, keeping them plugged in when practical may help verify condition before pickup. If a unit has already been disconnected, tell us whether it was working before it was unplugged.
