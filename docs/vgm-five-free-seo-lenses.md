# VGM Five Free SEO Lenses — California

This is a **free, read-only** reporting layer for the Verified Gold Model. It borrows the useful **methods** behind the Auditor, Researcher, Planner, Scorer, and Gatekeeper screenshots without copying third-party Claude skill code, paying for APIs, or installing any external package.

## Run
In the GitHub Actions tab, select **VGM Five Free SEO Lenses**, choose **Run workflow** and inspect its report artifact and job summary.

Or, from the repository root:

    python3 scripts/vgm-free-five-lenses.py --output vgm-five-lenses.md

## What it checks
- **Auditor:** static title, meta description, H1 count, owner-page canonical, sitemap/noindex inconsistencies, JSON-LD parse errors, and duplicate titles on selected California city hubs. Existing repository audits remain responsible for comprehensive internal links, images, mobile usability, and forms.
- **Researcher:** identifies general city owner pages and the query types to investigate in real Search Console data. It does not invent search volumes, ranking positions, or competitor data.
- **Planner:** checks for a link to an existing laundry-specific owner page, an accessible request/contact route, a telephone link, and relevant pickup-access instructions.
- **Scorer:** checks for structured service entities and FAQ text as a readability proxy. **It does not generate an AI citability score or prove an AI will mention us.**
- **Gatekeeper:** reports general directives in the repository's robots.txt. This does not verify live access by Googlebot, GPTBot, ClaudeBot, PerplexityBot, or any server/CDN restrictions.

## California priority
Rancho Cucamonga, Fontana, Upland, Claremont, La Verne, San Dimas, Pomona, Pasadena, Los Angeles, Riverside, Anaheim, and Irvine. Continue real appliance photos, distinct page intents, the published free-pickup qualification rules, and accurate contact forms.

## Guardrails
- This workflow has contents read permission only and does not commit, merge, crawl, request indexing, post links, or send leads.
- Do not change noindex, canonical, robots, form routing, or titles solely because a static report flags them. Preserve ongoing SEO experiments.
- Use actual Search Console query/page data and live competitor information before prioritizing ranking edits. An HTTP status check and real on-page rendering are separate from this static report.
- For backlinks, earn relevant real editorial/local references, not paid link schemes, fictitious memberships or fake service-area locations.
- A clean report is not evidence of better Google rankings, AI citations, or more customer calls.
