Start with the Treasure Valley guide

Boise and the Treasure Valley are the priority region for Idaho requests. The regional guide covers Boise, Meridian, Nampa, Caldwell, Eagle, Kuna and Star, with the appliance and access details needed for review.

View Treasure Valley pickup information

Elsewhere in Idaho

A Boise-area request does not establish coverage in northern, eastern or south-central Idaho. For an address outside the Treasure Valley, ask about availability with your city, ZIP code and appliance list before making removal arrangements.

We have not confirmed a statewide pickup schedule. Availability must be reviewed for the actual address; submitting a request does not reserve a truck or guarantee free removal.
