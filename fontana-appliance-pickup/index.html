Fontana Pickup Access: Garage, Driveway, Home or Rental

Fontana requests come from many different property types, so access information can determine whether the pickup is practical. Garage and driveway pickups are usually easier to review when the vehicle can get close to the appliance. Indoor pickups need more detail about doorways, turns, flooring, stairs and whether the appliance has been disconnected safely.

For apartments, condos and rental properties, provide the floor level, stair flights, elevator availability and any gate, parking or loading restrictions. For refrigerators, mention if the doors may have to come off to clear an exit. For stacked laundry, tell us whether the units are still installed.

Property managers replacing appliances in several units can submit the complete group in one request. List each item and its condition so the working percentage and access can be evaluated together.
