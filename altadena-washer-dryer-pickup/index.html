Altadena Washer & Dryer Pickup FAQ

Can one working machine qualify?

It may. A single working washer or dryer can be reviewed, while a complete working set receives stronger priority.

Can a machine upstairs or behind steps be reviewed?

Yes, but include the exact number of steps, turns and access limitations before scheduling.

Do you need photos?

Clear photos help verify condition and completeness and make routing more accurate.
