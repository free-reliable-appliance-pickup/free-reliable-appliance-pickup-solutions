# Ranking → Traffic → Lead → Pickup Measurement

## What V2 records for each form lead
- source service page
- first landing page in the session
- original referrer when available
- normalized source channel
- UTM source / medium / campaign / term / content
- Google Ads gclid when present
- Microsoft Ads msclkid when present
- Facebook fbclid when present
- anonymous session ID
- city, state, ZIP, appliance, condition and access details
- lead status and event history

## Important limitation
Organic search engines generally do **not** reveal the exact search query that one specific customer typed and then attach it to that customer's form submission.

For organic Google/Bing traffic, comparison is therefore done responsibly at the aggregate level:
1. search-performance data reports query + page + date + impressions + clicks + position
2. lead data reports source page + source channel + date
3. reporting compares the same page/time period to see which rankings and pages generate actual leads

Paid campaigns can be attributed more directly when click IDs or UTM tags are present.

## Funnel
Ranking / visibility → search click → landing page → form lead → reviewed opportunity → claimed job → completed pickup

## Why this matters
A page with a lower average position can still be more valuable if it produces more qualified leads. V2 will optimize for both visibility and business results, not rank alone.
